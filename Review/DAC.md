## Исходные замечания и выполненные правки

Номера строк ниже относятся к исходному обзору до правок.

### DAC-1 — P1 — Публичный статус больше не определён

**Место:** [src/dac.hpp](../src/dac.hpp), строка 19.

**Проблема:** SetUp() объявлен как SYS_StatusTypeDef, cpp возвращает SYS_OK. Эти имена отсутствуют в текущем System, где используются SysInitStatus/SysStatus.

**Последствие / условие:** DAC не компилируется с текущим ядром библиотеки.

**Возможное решение:** Перевести setup на согласованный SysInitStatus, без временных aliases старого API.

**Статус:** Исправлено: SetUp возвращает SysInitStatus::InitOK/InitError; старые имена удалены.

### DAC-2 — P1 — DACx игнорируется, запись регистра утрачивает volatile

**Место:** [src/dac.cpp](../src/dac.cpp), строка 9.

**Проблема:** SetUp обращается к глобальному DAC, а не DACx. data_out — uint32_t*, volatile регистров снят const_cast.

**Последствие / условие:** Переданный другой DAC не настраивается; compiler не обязан сохранять каждую hardware write в SetValue().

**Возможное решение:** Использовать проверенный DACx, data_out как volatile uint32_t*, не снимать volatile. Проверить доступность каналов данного экземпляра.

**Статус:** Исправлено: проверяется переданный DACx; все обращения выполняются через него. data_out имеет тип volatile uint32_t*, const_cast удалён. Доступность CH2 у F4 проверяется по CMSIS.

### DAC-3 — P1 — SetValue() до успешного setup разыменовывает неопределённый указатель

**Место:** [src/dac.hpp](../src/dac.hpp), строка 41.

**Проблема:** data_out не инициализирован, status/setup flag отсутствует. Недопустимый CHANNEL оставляет data_out неопределённым даже после SetUp.

**Последствие / условие:** Любой SetValue до setup или некорректный channel может записать произвольный адрес.

**Возможное решение:** Инициализировать pointer nullptr; SetUp валидирует device/channel и публикует pointer после успеха. SetValue возвращает простой NotInit/Error либо имеет ясно оговорённое предусловие.

**Статус:** Исправлено: data_out изначально nullptr и присваивается после настройки. SetValue возвращает NotInit до успешного SetUp и после DeInit. Некорректный экземпляр/канал отклоняется до обращения к аппаратуре.

### DAC-4 — P2 — F4-style clock/pins используются для всех семейств

**Место:** [src/dac.cpp](../src/dac.cpp), строка 5.

**Проблема:** RCC->APB1ENR/DACEN и PA4/PA5 жёстко зашиты. G0 clock register/name отличаются; не каждый MCU вообще имеет DAC.

**Последствие / условие:** Заявленная через CMake общая периферия не имеет корректной family/capability поддержки.

**Возможное решение:** Указать фактические поддерживаемые модели, выбрать корректные clock registers и pin/channel descriptors. Для отсутствующего DAC выдать ясную диагностику.

**Статус:** Исправлено: F4/F7 используют APB1ENR/DACEN, G0 — APBENR1/DAC1EN и MCR выбранного канала. МК без DAC дают явную ошибку компиляции; CH2 у F410 отклоняется. PIN формируется в списке инициализации, без запрещённого присваивания.

### DAC-5 — P3 — Нет явного контракта invalid value и lifetime

**Место:** [src/dac.hpp](../src/dac.hpp), строка 32.

**Проблема:** SetValue >0xFFF молча игнорируется. Копирование hardware-owning DAC_Module разрешено, destructor пустой, в tail header много пустых строк.

**Последствие / условие:** Ошибки значения незаметны; несколько копий могут управлять одной периферией без выбранного контракта.

**Возможное решение:** Согласовать clamp или Error; определить static lifetime/копирование как в других драйверах. Убрать пустой хвост и ненужные include после исправления API.

**Статус:** Исправлено: SetValue возвращает Error для значения >4095 без изменения регистра. DACx/канал закреплены в конструкторе и размещены в protected; служебный указатель в private. Копирование/перемещение запрещены, деструктор пассивный. Повторная настройка требует DeInit. Пустой хвост удалён; комментарии, примеры, DAC.md и README обновлены.

## Контракт и ограничения

- Один объект на аппаратный канал; отдельного реестра владельцев нет. CH1/CH2 независимы, вызовы изменения общей конфигурации нужно согласовывать.
- SetUp задаёт прямой 12-битный вывод с буфером и начальным кодом 0; второй канал не сбрасывается.
- DeInit отключает выбранный канал, сохраняя второй канал, DAC/GPIO clocks и analog-настройку пина.
- Успех API подтверждает настройку/запись регистра. Время аналогового запуска/установления учитывает приложение по datasheet.
- Компиляция с базой и работа на плате в этом проходе не подтверждались. Аппаратно остаётся проверить оба канала, сохранение второго при DeInit/SetUp первого, граничные значения и повторную настройку.
