# EXTI — согласованная реализация

Дата: 20.10.2026. Файлы: [exti.hpp](../src/exti.hpp), [exti.cpp](../src/exti.cpp).
Подробный API и примеры: [EXTI.md](../EXTI.md).

## Принятые решения

- Только внешние GPIO-линии 0–15, F4/F7/G0. Внутренние источники в этот модуль
  не включаются; их обслуживание относится к соответствующей периферии.
- EXTI_Line закрепляет PIN и Rising/Falling/Both конструктором. GPIO/подтяжку
  настраивает драйвер при SetUp. Новый PIN::GetNumber читает неизменяемый номер.
- Callback — protected virtual OnInterrupt, как в USART. Один объект — одна
  отдельная регистрация в существующем IRQ_Registry, без новых таблиц callback.
- Общая 16-битная маска отмечает занятые линии. Второй владелец того же номера
  (включая другой GPIO-порт) и повторный SetUp получают InitError до изменения
  аппаратуры. Отказ Register также возвращается как InitError с восстановлением NVIC.
- IRQ проверяет только разрешённый источник своей линии, читает pending один
  раз (на G0 два регистра по одному разу), подтверждает W1C и вызывает callback.
  Ожиданий/чтения GPIO/изменений реестра в IRQ нет.
- IRQ_en меняет только свою маску; DeInit адресно снимает регистрацию, освобождает
  линию и сохраняет других владельцев общего вектора. Конфигурация GPIO остаётся.
- EXTI_USE_ATOMIC=0 по умолчанию, при 1 — управляющие ATOMIC_* ST. Pending —
  прямые W1C. Полные операции и запись общих регистров сериализует вызывающий код.
- Модуль добавлен в стандартный список CMake как EXTI. Пользователь включает
  его через project.json; настройки реестра/атомарности остаются в заголовках.

## Явные ограничения

- IRQ_MAX_SHARED по умолчанию 3: на G0 общий EXTI4_15 допускает три объекта,
  четвёртый получает InitError. Аналогично общие группы F4/F7. Лимит не менялся.
- Уведомление не является точным счётчиком переходов. Для Both не определяется
  точный фронт; одновременные rising/falling flags G0 дают один callback.
- SetUp/DeInit — из main, с согласованием затронутых IRQ. Из callback менять
  конфигурацию/реестр нельзя. Встроенных блокировок, ожиданий и debounce нет.
- Объект живёт всё время регистрации; DeInit явный, деструктор аппаратуру не меняет.
