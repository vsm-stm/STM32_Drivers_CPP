## Возможные уточнения документации

- data должен быть доступен для чтения на len байтов; nullptr допустим при len==0. Отсутствие runtime nullptr-check не записывается как дефект при таком предусловии.
- crc32_update() принимает промежуточный raw CRC, crc32_finish() вызывается только в конце. Повторное finish между chunks меняет результат.
- CRC обнаруживает случайные повреждения, но не является механизмом аутентификации.

## Проверка при следующем запросе на тестирование

Контрольные vectors: пустая строка → 0x00000000; ASCII 123456789 → 0xCBF43926; сравнить один buffer и разбиение на несколько chunks. Проверить вызов из C++ base firmware. Замена на hardware CRC/lookup table сейчас не требуется.
