## Согласованное поведение

- Устройства с фиксированной организацией используют свой single/dual режим.
- У переключаемых режим выбирается `flash_bank_mode`; по умолчанию single.
- При работе драйвер проверяет режим МК; несовпадение возвращает InitError.
- Option bytes задаёт пользователь. Активный bank swap возвращает InitError.
- `flash_data::SetUp()` возвращает `SysInitStatus`.
- Для G4 с разрывом основной образ находится в первом банке, второй — явная секция.
- Карты обновляются для всех семейств в base_files; драйвер поддерживает F4/F7/G0.
- Обновление карты H7 не включает порт его платформы; база H7 остаётся запрещена.

## Карты и генератор

Генератор `STM32-base_files/flash_sectors.py` создаёт карты формата 3.
Для модели/объёма перечислены допустимые режимы, а для каждого режима — записи
`address, size, bank, number`. `number` содержит аппаратный селектор SNB/PNB.
Индекс сектора в таблице и селектор стирания разделены.

| Устройства в картах | Режимы |
|---|---|
| F427/429/437/439/469/479, 2 MiB | Фиксированный dual |
| Эти F4 с 1 MiB | Single / dual, DB1M |
| F765/767/769/777/779 | Single / dual, nDBANK |
| G0B0, 512 КиБ | Фиксированный dual |
| G0B1/C1, 512 КиБ | Фиксированный dual |
| G0B1/C1, 256 КиБ | Single / dual, DUAL_BANK |
| G0B1, 128 КиБ | Фиксированный single |
| G4 category 3 | Single 4 КиБ / dual 2 КиБ; у 128/256 КиБ разрыв адресов |
| F1 XL, 768/1024 КиБ | Фиксированный dual; первый банк 512 КиБ |
| L071/L072/L073 category 5, 128/192 КиБ | Фиксированный dual |
| L1 с 384 КиБ | Фиксированный dual, банки по 192 КиБ |
| H7 с 2 MiB из имеющейся карты | Dual; H7A3/B3 — страницы 8 КиБ |

Остальные имеющиеся модели получают допустимый single-режим, а H7B0 с 128 КиБ
использует страницы 8 КиБ. В G0-map добавлены модели из таблицы ST UM2303;
в L0-map — category-5 варианты L071/L072/L073. Для L1 исправлены ошибочные
CMSIS-селекторы плотности: xB для 128 КиБ, xC для 256 КиБ, xD для 384 КиБ.
Это необходимо для правильного выбора заголовков и геометрии устройств.

### Пример F429ZI

Выбирается dual автоматически. Два банка по 1 MiB, всего 24 сектора.
Банк 2 начинается с `0x08100000` и повторяет размеры 16/64/128 КиБ.
Запись таблицы с индексом 12 получает селектор SNB=16; последняя — SNB=27.

## База и linker

`project.json` принимает `flash_bank_mode`: `single`, `dual` или null/отсутствие.
Явный неподдерживаемый режим отклоняется. Для фиксированных устройств
null/отсутствие выбирает единственный режим; для переключаемых — single.

База разрешает одну карту и передаёт её linker и драйверам. Драйвер больше
не выбирает другую таблицу повторно по имени семейства/объёму.
Явный режим загрузчика должен совпадать с режимом приложения; при отсутствии
этой настройки загрузчик наследует выбранный режим платформы.

Для G4 с разрывом:

- Основной FLASH ограничен первым непрерывным банком выбранного окна образа.
- `.flash_bank2` размещает const-данные/функции в доступной части второго банка.
- Разрыв не входит в MEMORY, обычные секции не могут его занять.
- ELF/HEX содержат обе области с адресами.
- Основной BIN исключает `.flash_bank2`; отдельный `<target>.bank2.bin`
  программируется по адресу региона FLASH_BANK2 из сгенерированного .ld.
- Проверка основного образа загрузчиком не включает отдельную секцию банка 2.
  Проверку её данных реализует приложение.
- Адрес следующего образа загрузчика сохраняется даже при разрыве между банками.

## Flash-драйвер

- `init()` и `flash_data::SetUp()` возвращают `SysInitStatus`.
- Параметр `bank_type` по умолчанию соответствует карте; явный обязан совпадать.
- Для переключаемых F4/F7/G0 читаются соответствующие option bits.
- Для фиксированных режимов не используются не относящиеся к ним биты.
- При swap возвращается InitError; для F4/F7 читается активный MEMRMP при
  включённом SYSCFG clock, исходное состояние clock восстанавливается.
- Ошибка SetUp останавливает работу до разблокировки и поиска записей.
- Стирание и запись тоже проверяют режим перед операцией.
- Стирание сектора использует number/bank из карты; старые поля управления
  заменяются через маску. Для G0 выбирается BKER.
- Массовое стирание поддерживает маски 1, 2, 3; отсутствующий банк отклоняется.
- `ready()` на G0 учитывает оба BSY1/BSY2, если эти флаги доступны.

Остальные пункты обзора Flash остаются отдельными задачами: общий API ошибок
стирания/записи, таймауты, журнал данных, допустимые ширины программирования
и обслуживание кеша Flash. Эта правка не закрывает весь обзор модуля.

## Обновление существующего проекта

Нужны согласованные версии базы, драйверов и base_files. В скопированном проекте
(например TEST) обновляются `CMakeLists.txt`, `cmake/functions.cmake` и
`cmake/cmsis-download.cmake`. Затем обновляются сохранённые STM32-map.cmake,
flash_config.h.in и linker-шаблон либо задаётся STM32_BASE_FILES_DIR с путём
к этой рабочей копии base_files. Старые карты/шаблоны/драйверы отклоняются.
За время работы TEST был переключён пользователем на F746ZG. Обновлены три
CMake-файла базы, его сохранённая карта F7, linker-f7, flash_config-шаблон и
Flash-файлы/CMake библиотеки TEST/Drivers. Перед заменой проверены исходные
версии; пользовательских изменений в заменённых фрагментах не было. Маркер
DMA-поддержки старой библиотеки TEST не добавлялся: её System в этой задаче
не обновлялся. project.json и исходники приложения агент не менял.

Изменения base_files пока находятся в рабочей копии. При переключении TEST
на другой МК используйте STM32_BASE_FILES_DIR с путём к обновлённой рабочей
копии либо обновите данные на источнике скачивания: удалённая старая карта
формата 2 не содержит эту поддержку.
