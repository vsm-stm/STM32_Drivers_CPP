## Список для обсуждения

### MAP-1 — P2 — Mutable raw_entries() позволяет нарушить инварианты map

**Место:** [Containers/StaticMap.hpp](../Containers/StaticMap.hpp), строка 20.

**Проблема:** Наружу отдаётся Entry*, включающий key/used. Изменение used не синхронизирует used_count; изменение key может создать дубликаты несмотря на unique-key contract.

**Последствие / условие:** size() и результат lookup расходятся с фактическим содержимым. Это риск открытого escape hatch API; normal insert/erase этим не страдают.

**Возможное решение:** Выбрать контракт raw access: только чтение metadata и изменение value либо отдельный iteration API. Если mutable raw нужен, явно объявить обязанность поддерживать инварианты и не обещать автоматическую корректность.

**Статус:** согласованное ограничение 14.10.2026; изменяемый raw_entries() сохранён, ответственность описана в заголовке. Автоматических проверок и пересчёта size() нет.

### MAP-2 — P3 — Не описаны T lifetime и pointer invalidation

**Место:** [Containers/StaticMap.hpp](../Containers/StaticMap.hpp), строка 65.

**Проблема:** erase/clear не разрушают Key/Value; find возвращает pointer во внутренний slot, который при reuse означает другое значение. Типы должны быть default constructible/assignable.

**Последствие / условие:** Ожидания resource release и сохранения pointer могут отличаться от стандартного map.

**Возможное решение:** Документировать поддерживаемые типы, один контекст и инвалидирование результата find при erase/clear/reuse. Не добавлять heap или сложный ownership layer.

**Статус:** исправлено 14.10.2026; контракт описан в заголовке.

### MAP-3 — P3 — В header оставлен неиспользуемый код

**Место:** [Containers/StaticMap.hpp](../Containers/StaticMap.hpp), строка 81.

**Проблема:** Закомментированы два варианта for_each; type_traits подключён, но не используется.

**Последствие / условие:** Публичный интерфейс выглядит незавершённым и отвлекает от фактического raw_entries contract.

**Возможное решение:** После решения MAP-1 оставить один выбранный iteration путь, удалить мёртвые варианты и лишний include.

**Статус:** неиспользуемый код удалён 14.10.2026. Для публичного обхода сохранён raw_entries() по решению MAP-1.
