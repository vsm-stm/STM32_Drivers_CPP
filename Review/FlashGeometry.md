# Flash: компактная геометрия равномерных страниц

Дата: 20.10.2026. Согласованная правка для всех семейств с равномерной геометрией.
Сборки, тесты генератора и аппаратные тесты в этом проходе не запускались.

## Что изменено

- STM32_Drivers_CPP/CMakeLists.txt определяет представление из выбранной
  STM32_FLASH_ERASE_UNITS. Новых таблиц моделей или настроек project.json нет.
- STM32-base_files/cmake/flash_config.h.in генерирует конфигурацию формата 4.
  Исходные карты стирания и их формат 3 сохранены.
- Равномерная геометрия использует константы и формулу, без массива FlashSector
  по одному элементу на страницу. Неравномерная остаётся табличной.
- Единый интерфейс: GetFlashSector(index), возвращает FlashSector по значению.
  Входной индекс должен быть меньше FLASH_SECTOR_COUNT.
- Flash-драйвер и его журнал заменили прямые обращения к flash_sectors[] на этот
  интерфейс. В функциях с несколькими обращениями геометрия вычисляется один раз;
  при поиске записей вычисление вынесено за цикл.
- Правила программирования, стирания, статусы журнала, таймауты и проверки
  аппаратного режима банков этой правкой не менялись.

## Условия компактного представления

1. Размер всех страниц одинаков и положителен.
2. Один или два банка следуют в порядке логических индексов/адресов карты.
3. Внутри банка адреса идут с шагом размера страницы.
4. Аппаратные номера идут с шагом 1; первый номер берётся из карты отдельно.
5. Наличие второго банка соответствует выбранному режиму.

Начало второго банка не вычисляется как половина общей ёмкости: берётся его
первый адрес из карты. Поэтому разрывы G4 сохраняются, а F1 XL может иметь
неравные объёмы банков. Несоответствие любому условию оставляет исходную таблицу.

Детектор не проверяет имя семейства. Он применяется к любым выбранным картам
base_files, в том числе равномерным F0/F1/F3/G0/G4/H7/L0/L1. Для неравномерных
F2/F4/F7 используется таблица; если конкретная выбранная малая карта равномерна,
она тоже может быть компактной. Аппаратный Flash-драйвер остаётся F4/F7/G0:
компактное описание не портирует остальные семейства и не добавляет платформу H7.

## Формула

В одном банке:

    address = bank_origin + local_index * page_size
    number  = bank_first_number + local_index

Банк выбирается по количеству страниц первого банка. Для второго local_index
равен index - bank1_count. Деления и поиска в таблице в этом варианте нет.
Разрыв между банками не становится допустимой областью Flash.

Таблица из 256 FlashSector по 12 байт больше не требуется для равномерного G0.
Это удаление представления на 3072 байта, если прежняя таблица материализовалась
целиком; итоговая экономия образа не измерялась и зависит от компоновки/кода.

## Миграция

- Обновить драйверы и шаблон flash_config.h.in совместно. Старый конфиг формата 3
  отклоняется Flash-драйвером; старый шаблон — проверкой генератора CMake.
- Освежить кешированный шаблон в проекте и выполнить новую конфигурацию.
- Приложения с flash_sectors[index] переводятся на GetFlashSector(index).
  Для перебора используется index от 0 до FLASH_SECTOR_COUNT.
- При равномерной геометрии flash_sectors[] не объявлен. При неравномерной он
  остаётся реализацией GetFlashSector; прикладному коду следует использовать getter.
- Публичные операции flash_base/flash_data и номера логических секторов сохранены.
- Списки областей карты, настройки банков, project.json и linker не менялись.

Комментарии, Flash.md, README драйверов и README base_files обновлены.
